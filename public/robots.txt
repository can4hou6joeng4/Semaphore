# Semaphore crawl policy (repo source of truth).
#
# Decision (2026-08-13): AI *retrieval* is allowed, AI *training* is not.
# Assistants that fetch a page to answer a question are how a tool like this
# gets found now, and /llms.txt exists specifically to serve them. Training
# permission is a separate question and stays declined.
#
# The Content-Signal below is that declaration, and it is asserted HERE rather
# than by Cloudflare. Two zone-level settings used to control this and they are
# independent:
#
#   ai_bots_protection    — edge enforcement (blocking AI crawler requests).
#                           Set to "disabled" 2026-08-14.
#   is_robots_txt_managed — whether Cloudflare prepends its own managed block,
#                           which carried both the Content-Signal AND a blanket
#                           `Disallow: /` for nine AI user-agents. Turning the
#                           enforcement off did NOT remove those lines, because
#                           the managed text is generated independently. So the
#                           managed block was turned off too, and its one useful
#                           part — the Content-Signal — was moved into this file.
#
# Content-Signal meanings (per the content signals proposal):
#   search   building a search index and returning links/excerpts
#   ai-input taking content into an AI model at answer time (RAG, grounding)
#   ai-train training or fine-tuning models
# Restrictions expressed here are express reservations of rights under Article 4
# of EU Directive 2019/790.
#
# Googlebot was never affected by any of this: Google-Extended is the
# AI-training token, not the search crawler.

User-agent: *
Content-Signal: search=yes,ai-input=yes,ai-train=no
Allow: /
