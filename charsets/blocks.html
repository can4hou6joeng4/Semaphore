[ how_the_ramp_works ]

Five levels of fill, one per cell

The ramp is a space plus ░▒▓█. Each glyph paints a fixed fraction of its cell, so two neighbours on the same step join into one flat patch, and the edge appears only where the step changes. A photograph comes out as terraces. That banding is the result this ramp is for; raise contrast to push the terraces apart.

The site's own font subset contains ░▒▓█, so the preview uses that face. A destination font may substitute another, and the four shades keep their order. See every charset side by side on the home page.

Where block characters stand out

$ pixel-art look

Because block elements occupy full cell boundaries rather than thin strokes, converted logos and sprites read as oversized pixels, producing an authentic 8-bit retro aesthetic.

$ line-height calibration

Ensure destination text containers specify line-height: 1.0. Excessive line spacing introduces horizontal gaps between rows that fracture otherwise solid fills.

$ terrace banding

With only 5 discrete fill steps, natural photos develop bold topographical bands. Increasing contrast pushes these terraces apart into dramatic posterized forms.

[ faq ]

Block charset questions

What are the Unicode block elements used in this charset?

The ramp uses four standardized Unicode Block Elements: Light Shade (░, U+2591, 25% fill), Medium Shade (▒, U+2592, 50% fill), Dark Shade (▓, U+2593, 75% fill), and Full Block (█, U+2588, 100% solid).

Why do block characters sometimes show horizontal or vertical gaps?

Block glyphs are designed to touch cell borders seamlessly. If gaps appear, the destination environment is enforcing a line-height greater than 1.0 or using a font with non-standard glyph bounding boxes. Setting line-height: 1 in CSS or terminal profiles restores seamless mosaic tiles.

When should I choose blocks over standard ASCII or braille?

Choose blocks for pixel art, retro gaming sprites, high-contrast posters, and README marquee headers where solid silhouette impact matters more than photographic realism.
