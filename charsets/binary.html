Three steps means shape, not shade

The ramp is a space, 0 and 1. There is no fourth step, so a gradient has nowhere to go: shadow is the space, the middle is 0, the highlight is 1. What remains is the boundary between them.

Contrast decides where those two cuts fall. Invert swaps which digit carries the subject, so the picture changes rather than merely darkening. Both digits are 7-bit ASCII. The full set of ramps is on the home page.

1-Bit Storage & Telemetry

Because every character is restricted to {space, 0, 1}, the output is trivially parsed and packed into bitstreams for constrained microcontrollers and serial monitors.

Frequently asked questions

How does the binary ASCII ramp work?

The binary ramp uses only three levels: Space (0–33% luma), digit '0' (34–66% luma), and digit '1' (67–100% luma). It discards subtle gradients to render stark, high-contrast digital silhouettes.

What visual aesthetic is binary ASCII best for?

It is suited for cyberpunk visuals, Matrix-style code rain terminal screens, machine-readable text patterns, and high-impact graphic stencil art.

How does the invert toggle change binary output?

Toggling invert flips the threshold cuts, switching whether '1' represents highlights or shadows. On dark terminal backgrounds, inverting lets you choose whether the subject glows or reads as negative space.
