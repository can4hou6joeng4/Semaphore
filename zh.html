图片转 ASCII 字符画

Semaphore 把图片变成可复制的纯文本字符画。全程在你的浏览器里完成：没有上传接口、没有账号、没有页面内统计脚本。生产环境 CSP 为 connect-src 'none'，页面本身也无法对外发起网络请求。

[ 字符集 ]

六套字符集，按层级排列

引擎对每个网格单元算出一个感知亮度值，再挑出「墨量」最接近的字符。字符集决定了可选的字符表，也就决定了输出的质感。层级越多，能表达的灰阶越细；层级越少，越偏向轮廓而非明暗。

列数可在 40 至 240 之间调节，默认 120；亮度与对比度各为 -100 至 +100。等宽字符单元大约宽三份、高五份，所以方形图在 120 列下会输出 72 行——粘贴到度量不同的字体里会被拉伸，字符是对的，网格不是。

[ 隐私 ]

为什么可以说「不上传」

常见在线转换站会把文件发到服务器。Semaphore 没有后端 API。图片字节只在你的标签页里被读取；你只会在主动复制或下载时把结果带出浏览器。主题与最近使用的字符集/配色偏好保存在本机 localStorage，从不包含图片内容。

[ 常见问题 ]

常见问题

Q 图片会被上传到什么地方吗？

不会。转换完全通过浏览器的 canvas API 在本地完成，页面加载完成后即使断网也能用。如果你倾向于自己验证，打开开发者工具的网络面板，它应当保持安静。

Q 页面里跑统计脚本吗？

没有。页面不含统计脚本、不用 cookie，CSP 设为 connect-src 'none'，因此它无法向任何地方发起 fetch、XHR 或 WebSocket。运营者能看到的只有 Cloudflare 边缘的聚合 HTTP 请求量——那是页面加载本身的服务器日志，不是你标签页里的二次回传，其中从不包含图片字节。

Q 是免费的吗？

免费，无需账号，没有水印，没有每日配额。整个工具以静态文件形式发布，采用 MIT 许可。

Q 会记住我的设置吗？

只保存少量偏好在你的设备上：配色主题（CRT 或纸质），以及你在工具里最后选择的字符集和配色模式。它们存在 localStorage 里，从不包含图片字节。「reset params」会清空工具偏好；URL 查询参数在存在时仍然优先。

Q 支持哪些图片格式？

你的浏览器能解码的都可以：png、jpg、webp 和 gif（取首帧）。拖入、粘贴或浏览选择均可。

Q 怎样得到更清晰的结果？

从高对比、裁剪紧凑的图开始。把列数提到 160 至 200，对比度加约 +15；若主体是深色压在浅底上，试试反相。要照片级细节，braille 是最锐利的那一套。

Q 盲文模式究竟在做什么？

每个字符变成一个取自 Unicode 盲文区的 2×4 点阵，并用 Floyd–Steinberg 误差扩散做抖动——空间分辨率约为传统字符表的八倍。它需要含盲文字形的字体，现代操作系统都自带。

Q 能保留原图颜色吗？

可以。配色模式 original 按字符采样源图颜色，gray 保留中性灰阶，green 是经典荧光屏观感。颜色会保留在 .png 导出里；纯文本复制在本质上只有字符。

Q 输出可以商用吗？

输出属于你——海报、README、周边、客户项目都可以。我们不对你的作品主张任何权利。

Q 有尺寸限制吗？

Semaphore 不设固定的源图尺寸上限，实际上限取决于你的浏览器和可用内存。输出限制在 40 至 240 列。高列数下的密集盲文在老设备上可能更慢。
